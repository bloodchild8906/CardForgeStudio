# Data model

CardForge stores all authored content as JSON under `Assets/CardForgeData`. The models are plain `[Serializable]` classes in `Assets/CardForge/Runtime/CardForgeModels.cs`, serialized with Unity's `JsonUtility`.

Related: [file-map.md](file-map.md), [designer-guide.md](designer-guide.md), [rules-and-flows.md](rules-and-flows.md), [runtime-guide.md](runtime-guide.md).

## Serialization rules

- Public camelCase fields are written as-is (`"layoutId"`, `"cardNumber"`).
- `JsonUtility` writes enums as integers.
- `List<T>` and nested `[Serializable]` classes are supported.
- `null` lists are normalized to empty lists on `CardForgeStore.Reload`.
- Files are written pretty-printed with `JsonUtility.ToJson(data, true)`.
- Writes are atomic: write `<file>.tmp`, copy over the target, delete the temp.
- `JsonUtility` ignores unknown JSON members; missing members get C# defaults.
- There is no general-purpose dictionary serialization. Use lists of pairs/objects.

## IDs

- New ids are `Guid.NewGuid().ToString("N")`: 32 lowercase hex characters, no dashes.
- `SafeId` accepts only letters, digits, `-` and `_`, up to 128 characters. Any other id throws `InvalidOperationException`.
- Ids are stable across renames and are the primary key in every dictionary.
- Import validates ids with the same rules; invalid or duplicate ids reject the import.
- Ids are used as file names, so never put spaces or punctuation in them.

## Storage layout

```
Assets/CardForgeData/
  schema.json
  blocks/<blockId>/block.json
  blocks/<blockId>/layouts/<layoutId>.json
  blocks/<blockId>/cards/<cardId>.json
  blocks/<blockId>/export-manifest.json     (generated by export)
  icons/<iconId>.json
  icons/<iconId>.png                         (optional generated raster)
  turn-flows/<id>.json
  triggers/<id>.json
  actions/<id>.json
  abilities/<id>.json
  keywords/<id>.json
  fonts/<family>/...
  frames/...                                 (created by Frame Composer)
  icon-sets/...                              (created by Icon Set Studio)
```

Layouts and cards live inside their owning block folder. Rules and icons are global to the project.

## Schema

`schema.json` is a `SchemaDocument`:

```json
{
  "version": 1,
  "fields": [
    {
      "id": "7e1150461ebe451eb04d2d9733b3ef71",
      "key": "title",
      "label": "Card Name",
      "kind": 0,
      "defaultValue": "New Discovery",
      "help": "",
      "decimalPlaces": 0,
      "prefix": "",
      "suffix": ""
    }
  ]
}
```

### FieldDefinition

| Field | Type | Notes |
| --- | --- | --- |
| `id` | string | Stable field id. |
| `key` | string | Unique machine key. Used as `field:<key>` in imports. |
| `label` | string | Human label. |
| `kind` | `FieldKind` int | See enum below. |
| `defaultValue` | string | Used when a card has no value. |
| `help` | string | Help text. |
| `decimalPlaces` | int | Number display precision. |
| `prefix`, `suffix` | string | Display decoration. |

### FieldKind

| Name | Value |
| --- | --- |
| `Text` | 0 |
| `Number` | 1 |
| `Icon` | 2 |
| `Image` | 3 |
| `Boolean` | 4 |

Seeded fields: `title`, `cost`, `type`, `rules`, `power`, `art` (Image), `faction` (Icon).

## Block

`blocks/<id>/block.json`:

```json
{
  "version": 1,
  "id": "9d501abea1464fbd963fba15d4fe1b5b",
  "code": "CORE",
  "name": "Core Set",
  "description": "",
  "layoutIds": ["..."],
  "cardIds": ["..."],
  "defaultBackLayoutId": "..."
}
```

| Field | Type | Notes |
| --- | --- | --- |
| `version` | int | Document version. |
| `id` | string | Block id. |
| `code` | string | Short set code; used in bundle names. |
| `name` | string | Display name. |
| `description` | string | Notes. |
| `layoutIds` | string[] | Owned layouts. |
| `cardIds` | string[] | Owned cards. |
| `defaultBackLayoutId` | string | Default back for new cards. |

## Layout

`blocks/<blockId>/layouts/<layoutId>.json`:

```json
{
  "version": 1,
  "id": "5435a961e1bf4876b2b233ae723c5f14",
  "name": "Front - Creature",
  "isBack": false,
  "width": 360,
  "height": 504,
  "backgroundAssetPath": "Assets/CardForgeData/...",
  "backgroundColor": "#131d2b",
  "templates": [],
  "zones": [],
  "layoutType": "Standard",
  "requirements": []
}
```

| Field | Type | Notes |
| --- | --- | --- |
| `id` | string | Layout id. |
| `name` | string | Display name. |
| `isBack` | bool | Back-face flag. |
| `width`, `height` | int | Card size in pixels; minimum 50 each. |
| `backgroundAssetPath` | string | Optional background texture under `Assets/`. |
| `backgroundColor` | string | `#RRGGBBAA`. |
| `templates` | `ZoneTemplateDefinition[]` | Reusable slice backgrounds. |
| `zones` | `ZoneDefinition[]` | Content zones. |
| `layoutType` | string | Free-form type. |
| `requirements` | `RequirementDefinition[]` | Layout-level gating. |

## Zone

A `ZoneDefinition`:

| Field | Type | Notes |
| --- | --- | --- |
| `locked` | bool | Cannot be edited on canvas. |
| `id` | string | Stable zone id; referenced by card overrides. |
| `name` | string | Display name. |
| `kind` | `ZoneKind` int | See enum. |
| `fieldId` | string | Bound schema field (empty for static). |
| `staticText` | string | Literal text. |
| `staticAssetPath` | string | Literal image. |
| `x`, `y`, `width`, `height` | float | Pixel rectangle. |
| `order` | int | Draw order. |
| `offsetX`, `offsetY` | float | Text offset. |
| `fontSize` | float | Text size. |
| `fontAssetPath` | string | Font asset. |
| `color` | string | Text color `#RRGGBBAA`. |
| `backgroundColor` | string | Zone background. |
| `templateId` | string | Optional `ZoneTemplateDefinition`. |
| `bold` | bool | Bold text. |
| `visible` | bool | Authoring visibility. |
| `alignment` | string | `TextAnchor` name, e.g. `MiddleCenter`. |
| `layers` | `ZoneLayer[]` | Container surfaces. |
| `variants` | `ZoneVariant[]` | Conditional alternatives. |

### ZoneKind

| Name | Value |
| --- | --- |
| `Text` | 0 |
| `Number` | 1 |
| `Icon` | 2 |
| `Image` | 3 |
| `StaticText` | 4 |

### ZoneTemplateDefinition

| Field | Notes |
| --- | --- |
| `id`, `name` | Identity. |
| `backgroundAssetPath`, `backgroundColor` | Appearance. |
| `imageScaleMode` | `ZoneImageScaleMode`. |
| `sliceLeft`, `sliceRight`, `sliceTop`, `sliceBottom` | Nine-slice insets (default 12). |

### ZoneImageScaleMode

| Name | Value |
| --- | --- |
| `Stretch` | 0 |
| `Cover` | 1 |
| `Contain` | 2 |
| `Tile` | 3 |
| `Slice` | 4 |

### ZoneLayer

| Field | Notes |
| --- | --- |
| `id`, `name` | Identity. |
| `order` | Draw order. |
| `visible` | Visibility. |
| `blendMode` | Stored; **not applied** by the renderer. |
| `opacity` | 0-1. |
| `backgroundColor` | `#RRGGBBAA`. |
| `assetPath` | Image texture. |
| `templateId` | Slice template. |
| `bindingPath` | Optional field binding. |
| `requiredCardType` | Restrict to a card type. |
| `requirements` | Gating. |
| `imageScaleMode`, `slice*` | Image slicing. |

### ZoneVariant

| Field | Notes |
| --- | --- |
| `id`, `name` | Identity. |
| `layerId` | Layer whose visibility/opacity applies. |
| `staticText`, `staticAssetPath` | Replacement content. |
| `x`, `y`, `width`, `height` | Replacement geometry. |
| `fontSize`, `color` | Replacement text style. |
| `visible` | Combined with the source zone's visibility. |
| `requirements` | Used when the card has no explicit `variantId`. |

## Card

`blocks/<blockId>/cards/<cardId>.json`:

```json
{
  "version": 1,
  "id": "9c528d2da9ac428fad9da4e893102942",
  "name": "Ember Drake",
  "cardNumber": "001",
  "layoutId": "5435a961e1bf4876b2b233ae723c5f14",
  "backLayoutId": "82333acefa694a4da489e4bb3d81ff72",
  "sourceBlockId": "",
  "sourceCardId": "",
  "cardType": "Creature",
  "variantId": "",
  "values": [
    { "fieldId": "7e1150461ebe451eb04d2d9733b3ef71", "value": "Ember Drake" }
  ],
  "zoneOverrides": [],
  "requirements": [],
  "keywordIds": [],
  "abilityIds": []
}
```

| Field | Notes |
| --- | --- |
| `name` | Card name. |
| `cardNumber` | Display number, `001` by default. |
| `layoutId` | Front layout id. |
| `backLayoutId` | Optional back layout id. |
| `sourceBlockId`, `sourceCardId` | Reprint provenance. |
| `cardType` | Used by layer `requiredCardType`. |
| `variantId` | Forces a zone variant. |
| `values` | `CardFieldValue[]` (`fieldId`, `value`). |
| `zoneOverrides` | Per-card tweaks. |
| `requirements` | Card gating. |
| `keywordIds` | Keyword references. |
| `abilityIds` | Ability references. |

### ZoneOverride

| Field | Notes |
| --- | --- |
| `zoneId` | Target zone. |
| `deltaX`, `deltaY`, `deltaWidth`, `deltaHeight` | Offsets from layout geometry. |
| `fontSize` | `0` inherits. |
| `color` | Empty inherits. |
| `textOverride` | Literal text replacement. |
| `assetPathOverride` | Image replacement. |
| `hidden` | Hide the zone for this card. |

## Requirement

`RequirementDefinition`:

| Field | Notes |
| --- | --- |
| `id` | Requirement id. |
| `fieldId` | Field to test. |
| `comparison` | `Equals`, `Not equals`, `Contains`, `Greater than`, `Greater than or equal`, `Less than`, `Less than or equal`. |
| `expectedValue` | Compared as text; numeric when both parse. |
| `message` | Optional explanation. |

### TurnFlowNode

| Field | Notes |
| --- | --- |

| `phase` | Phase category. |

### PhaseActionRule

| Field | Notes |

### TurnFlowLink

## Action

`actions/<id>.json`:

| Field | Notes |
| --- | --- |
| `version`, `id`, `name` | Identity. |
| `triggerId` | Optional viability trigger. |
| `resolution`, `effect`, `condition`, `cost`, `targets` | Rules text. |
| `orientationChange` | `CardOrientationChange`. |

### CardOrientationChange

## Icon

`icons/<id>.json`:

| Field | Notes |
| --- | --- |
| `version` | `2` for current icons. |
| `id`, `name` | Identity. |
| `assetPath` | Optional PNG under `Assets/`. |
| `layers` | `IconLayer[]`. |

### IconLayer

`visible`, `opacity`, `shape` (`Circle`, `Ring`, `Square`, `Diamond`, `Triangle`, `Star`, `Bolt`, `Shield`, `Cross`), `color`, `x`, `y` (0-1), `size` (0-1), `rotation`.

Older icons (`version < 2`) are upgraded on load: layers get `visible = true` and `opacity = 1`, and the version becomes 2.

## Export manifest

`blocks/<id>/export-manifest.json` is written by `ExportBlock`:

```json
{
  "version": 1,
  "blockId": "...",
  "blockName": "Core Set",
  "bundleName": "cards-core-9d501abe",
  "unityBuildTarget": "StandaloneWindows64",
  "jsonAssetPaths": ["Assets/CardForgeData/schema.json", "..."],
  "imageAssetPaths": ["..."],
  "fontAssetPaths": ["..."]
}
```

The runtime reader identifies data by this manifest, not by asset file names. See [import-export.md](import-export.md) and [runtime-guide.md](runtime-guide.md).

## Runtime-only types

These are compiled, not authored:

| Type | Purpose |
| --- | --- |
| `RuleStateMachineDefinition` | Compiled flow, triggers, actions, abilities, keywords, states. |
| `RuleStateDefinition` | One phase: action rules, abilities, transitions. |
| `RuleStateTransition` | Target state + condition + resolution. |
| `RuleCompiledAction` | Ordered graph steps, state-change steps, trigger boundaries, caused triggers. |
| `RuleResponseWindow` | Open response window: players, passes, response stack. |
| `RuleResponseEntry` | One response: sequence, player, trigger, action. |
| `RuleEngineResult` | Kind, reason and ids from an engine call. |
| `ExportManifest` | Bundle contents. |

## Helpers

`CardForgeData`:

| Method | Purpose |
| --- | --- |
| `NewId()` | New 32-hex id. |
| `Copy<T>(T)` | Deep clone through JSON. |
| `Value(card, field)` | Card value or field default. |
| `SetValue(card, fieldId, value)` | Insert/update a card value. |
| `GetOverride(card, zoneId)` | Find a zone override. |
| `EnsureOverride(card, zoneId)` | Find or create one. |
