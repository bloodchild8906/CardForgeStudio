- [Architecture](architecture.md) — systems, ownership and service boundaries.
- [Native server operations](native-dedicated-server.md) — build, startup, storage, API and security.
- [Editor publishing and playing](editor-server-workflow.md) — authoring, export, live upload, client readiness.
- [Game package format](game-package-format.md) — how a designer package becomes native simulation data.

Editor-specific guidance in `Editor/docs` remains useful for card and layout authoring; native runtime instructions in this folder take precedence over any older server text.
